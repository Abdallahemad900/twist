# Supplied 21st.dev components

The user supplied both components directly in pasted files. Their original code is archived in the local project. This repository includes the integrated website components only.

- [Lycoris Specimen by kedhareswer](https://21st.dev/@kedhareswer/components/lycoris-specimen): the hold/ease `sceneCoord` helper and six-camera-frame architecture are adapted in `src/components/ui/lycoris-waypoints.ts`. The flower renderer is replaced with the existing Blueberry Island GLB in `CanScene.tsx`.
- [Onyx / Black Metal Logo Preloader by kedhareswer](https://21st.dev/@kedhareswer/components/onyx-glyph-preloader): integrated in `src/components/ui/onyx-glyph-preloader.tsx`, with Twist glyphs, a blue metal palette, real hero readiness, skip/timeout handling, and Arabic progress announcements.

Both were identified through the connected 21st.dev catalog. No paid retrieval, hosted generation, or registry API key was needed because the user supplied the source. Component provenance is preserved by the links above.

Reference photos are the user's supplied screenshots, copied unchanged to `public/media`. CSS crops their presentation. The six-can images and all GLBs are from the existing V2 model package. This redesign did not generate or modify Blender models.
